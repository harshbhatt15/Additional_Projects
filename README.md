## 🚀 Getting Started

1. Clone the repository

```bash
git clone https://github.com/harshbhatt15/Additional_Projects.git
```

2. Navigate into the repository

```bash
cd Additional_Projects
```

3. Install dependencies

```bash
pip install -r requirements.txt
```

> If a project doesn't include a `requirements.txt`, install the required libraries mentioned in its notebook or source code.
