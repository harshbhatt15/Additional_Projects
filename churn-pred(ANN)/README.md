# Customer Churn Prediction using Autoencoder + ANN

---

## Project Description

This project predicts whether a **bank customer will leave the bank (churn) or stay** using Deep Learning.

The model uses two main components:

- **Autoencoder** → Compresses input features into a smaller representation.
- **Artificial Neural Network (ANN)** → Uses the compressed features to classify customer churn.

The goal is to improve prediction performance by learning better feature representations.

---

## Dataset

Dataset used: **Customer Churn Modelling**

It contains customer information such as:

- Credit Score
- Geography
- Gender
- Age
- Tenure
- Balance
- Number of Products
- Has Credit Card
- Is Active Member
- Estimated Salary

Target Variable:
Exited
0 → Customer stays
1 → Customer leaves the bank
